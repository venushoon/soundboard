# 🎹 기계식 사운드보드

키보드를 눌러 효과음과 배경음악을 재생하는 **공연·방송용 사운드보드**입니다.
효과음 자판 15키 × 2뱅크, BGM 숫자패드 9키, 채널별 볼륨 믹서, 큐(순서 재생) 모드,
그리고 올리는 족족 음량을 자동으로 맞춰 주는 라우드니스 보정까지 들어 있습니다.

## 🚀 바로 사용하기

**👉 https://venushoon.github.io/soundboard/**

설치도 회원가입도 필요 없습니다. 접속하면 예시 사운드 13개가 자판에 배치된 상태로 바로 눌러 볼 수 있습니다.
이 공개 버전은 **브라우저 저장 방식**이라, 올린 음원과 배치는 내 브라우저 안에만 저장됩니다.
기기·브라우저를 바꿔도 그대로 쓰고 싶으면 아래 [서버로 직접 운영하기](#-서버로-직접-운영하기)를 참고하세요.

## 🎛️ 화면 구성

### 효과음 자판 (문자 키)

```
Q  W  E  R  T
A  S  D  F  G
Z  X  C  V  B
```

- 키를 누르거나 클릭하면 재생됩니다. **여러 키를 동시에** 눌러도 겹쳐서 재생됩니다.
- 자판 위쪽의 **뱅크 A / B 전환**으로 배치 세트를 통째로 바꿀 수 있습니다(슬롯 총 30개).
  큐는 현재 뱅크 기준으로 재생되니, 큐를 만들 때와 재생할 때 뱅크를 맞춰 주세요.
- 빈 키는 [자판 설정](#️-자판-설정편집-모드)이나 라이브러리에서 사운드를 배치하면 채워집니다.

### BGM 키패드 (숫자 키)

```
7  8  9
4  5  6
1  2  3
```

- 키를 누르면 재생/일시정지 토글. 다른 BGM을 켜면 재생 중이던 BGM은 **페이드아웃되며 전환**됩니다(한 번에 하나만).
- 재생이 시작되면 화면 아래에 **재생 바**가 떠서 정지 · 위치 탐색(시크) · 반복 재생을 조작할 수 있습니다.

### 공통 조작

| 조작 | 동작 |
| --- | --- |
| `Esc` | 전체 정지 (재생 중인 모든 소리 즉시 중단) |
| `Space` | 큐 모드에서 다음 큐 실행 (GO) |
| 마우스/터치 | 모든 키와 버튼을 클릭·탭으로도 조작 가능 |

## 🎚️ 볼륨 믹서

자판 아래의 믹서 패널에서 **배치된 키만 채널로** 모아 실시간으로 볼륨을 조절합니다.

- 채널마다 세로 페이더가 있고, 범위는 **0~200%**입니다. 정중앙이 100%이며, 100%를 넘기면 % 숫자가 주황색으로 바뀝니다.
- 페이더 옆에 **레벨 미터**가 있어 각 채널이 실제로 얼마나 크게 나가는지 눈으로 확인할 수 있습니다.
- 최종 출력에는 **리미터**가 걸려 있어 여러 소리가 겹쳐도 찌그러지지 않게 자동으로 눌러 줍니다.
- 페이더를 **더블클릭**하거나 **% 숫자를 클릭**하면 그 채널만 100%로 돌아갑니다.
- 헤더의 **↺ 초기화**를 누르면 배치된 전 채널이 100%로 초기화됩니다(라이브러리의 사운드별 음량 보정은 건드리지 않음).
- 처음 접속하면 공간을 아끼도록 **접힌 상태**로 시작합니다. 펼치기/접기 선택은 기억됩니다.
- **🪟 창으로 띄우기**를 누르면 믹서만 별도 창으로 분리됩니다. 듀얼 모니터의 보조 화면에 올려 두고 쓰기 좋고,
  창 상단 메뉴에서 뱅크 전환 · 전체 정지 · 초기화를 바로 할 수 있습니다.
- 자판 설정(편집 모드)에서는 믹서가 숨겨집니다. 편집 모드의 키별 볼륨 슬라이더를 쓰세요.

## 📚 라이브러리

상단 **📚 라이브러리** 탭에서 음원을 폴더별로 관리합니다.

- **폴더(카테고리)** 만들기 · 이름 변경 · 삭제 (삭제하면 안의 사운드는 `미분류`로 이동)
- **다중 업로드** — 파일을 여러 개 한 번에 올릴 수 있고, 올릴 때 효과음/BGM 종류와 폴더를 지정합니다
- 검색, 카드별 미리듣기, 다운로드, 이름 변경, 폴더 이동
- 카드에서 바로 **자판 키에 배치** (효과음은 문자 키, BGM은 숫자 키)
- 사운드마다 아래 [음량 자동 보정](#-음량-자동-보정라우드니스)이 표시되고 조절할 수 있습니다
- **⏱ 구간·페이드** — 파일을 편집하지 않고 재생할 **시작/종료 지점(초)**만 지정하거나, **페이드 인/아웃(초)**을 걸 수 있습니다.
  긴 음악의 필요한 부분만 잘라 쓰거나, BGM이 서서히 시작하고 끝나게 할 때 씁니다. 정지 버튼을 눌러도 페이드아웃 시간에 걸쳐 서서히 멈춥니다.

## ⚙️ 자판 설정(편집 모드)

상단의 자판 설정 버튼을 켜면 편집 모드가 됩니다.

- 키를 선택해 사운드 배치/해제, 라벨 변경, 반복 재생, 키별 볼륨을 설정합니다.
- 키마다 **색상**을 지정할 수 있습니다(팔레트에서 선택). 어두운 곳에서 키를 빨리 찾기 좋습니다. 색상은 뱅크별로 저장됩니다.
- 파일을 직접 올려서 그 키에 바로 배치할 수도 있습니다.

## 🎬 큐 모드

공연처럼 정해진 순서대로 소리를 내야 할 때 쓰는 모드입니다.

- 큐 플레이어 창에서 음원 추가, 메모 입력, 구분선(제목 지정) 삽입, 순서 변경, 삭제가 됩니다.
- `Space` 또는 GO 버튼으로 다음 큐를 실행합니다. 자판 위의 GO 바에 다음 큐가 표시됩니다.
- 큐 플레이어는 독립 창으로 띄워 둘 수 있습니다.
- **🌗 페이드 큐** — 재생 중인 BGM(또는 전체 소리)을 정해진 시간에 걸쳐 서서히 줄여 멈추는 큐를 식순에 넣을 수 있습니다.
- **자동 진행** — 큐마다 진행 방식을 정할 수 있습니다. `끝나면 자동 진행`은 그 큐가 끝나면 다음 큐를 알아서 실행하고,
  `다음 큐 동시 시작`은 두 큐를 겹쳐서 시작합니다. GO를 기다리는 `수동`이 기본입니다.
- **대기(프리웨이트)** — 큐마다 실행 지시 후 실제로 울리기까지의 지연 시간(초)을 줄 수 있습니다.

## 🔊 음량 자동 보정(라우드니스)

음원마다 소리 크기가 제각각인 문제를 해결합니다.

- 업로드하면 음량을 자동 측정해 **기준 음량 -16 LUFS**에 맞춰 재생 게인을 보정합니다.
  큰 소리는 줄이고 작은 소리는 키우되, 보정 후 피크가 **-1 dBTP**를 넘지 않게 막아 찌그러짐을 방지합니다.
- 라이브러리 카드에 측정 음량(LUFS)과 적용 보정(dB)이 표시됩니다.
- 사운드별로 보정을 끄거나, 미세 조정(±dB)으로 귀에 맞게 더하고 뺄 수 있습니다.
- **전체 음량 균일화** 버튼으로 라이브러리 전체를 한 번에 다시 분석·보정할 수 있습니다.

## 💾 내 데이터는 어디에 저장되나요?

| | 브라우저 저장 (공개 페이지) | 서버 저장 (직접 운영) |
| --- | --- | --- |
| 음원 파일 | 내 브라우저의 IndexedDB | 서버의 `data/files/<폴더>/` 실제 파일 |
| 배치·큐·설정 | 내 브라우저의 localStorage | 서버의 `data/db.json` |
| 다른 기기에서 | 이어서 쓸 수 없음 | 같은 서버에 접속하면 그대로 |
| 주의 | 브라우저 데이터를 지우면 사라짐 | 서버 데이터 폴더만 지키면 됨 |

- 예전(브라우저 저장) 버전에서 쓰던 데이터가 있으면, 새 버전 첫 실행 때 **자동으로 승계**됩니다.
  서버 버전을 처음 열 때도 기존 브라우저 저장분을 서버로 옮길 수 있는 안내가 뜹니다.
- 어느 방식이든 헤더의 **내보내기**로 자판 배치 · 큐 · 음원 파일까지 담은 백업(JSON)을 만들 수 있고, **가져오기**로 복원할 수 있습니다.

## 📦 서버로 직접 운영하기

```bash
docker compose up -d --build
# http://<서버 IP>:8900
```

- Node(Express) 서버가 음원 파일과 메타데이터를 보관하고, 프론트와 API를 함께 서빙합니다.
- 첫 실행 시 예시 사운드 13개가 자동으로 심어지고 자판에 배치됩니다.
  시드 목록은 `public/seeds/manifest.json`, 원본 파일은 같은 폴더의 mp3입니다(파일이 없으면 그 사운드만 건너뜀).

## 🛠️ 개발

```bash
npm install
npm run dev          # 개발 서버
npm run build        # 서버 저장 모드 빌드 (Docker 배포용)
npm run build:pages  # 브라우저 저장 모드 빌드 (GitHub Pages, /soundboard/ 경로)
npm run deploy       # gh-pages로 배포 (build:pages 결과물 기준)
npm start            # 서버 단독 실행 (node server/index.js)
```

구조 한눈에 보기:

- `src/` — React + Vite + Tailwind 프론트엔드, WebAudio 재생 엔진
- `src/storage/` — 저장 어댑터. `api.js`가 빌드 모드에 따라 `serverApi`(서버 저장) / `localApi`(브라우저 저장)를 골라 내보내며,
  앱 코드는 어느 모드인지 몰라도 됩니다. 서버 모드 빌드에서는 브라우저 저장 코드가 번들에서 빠집니다.
- `src/storage/browserLoudness.js` — 서버의 ffmpeg 측정을 대신하는 브라우저 내 BS.1770 라우드니스 측정
- `src/storage/seedSynth.js` — 브라우저 모드의 예시 사운드를 WebAudio로 합성 (바이너리 시드 파일이 없어도 되게)
- `server/` — Express 백엔드 (`index.js`), ffmpeg 기반 라우드니스 측정 (`loudness.js`)
